# docs

`nustack.dev/docs`: fumadocs app, served under the `/docs` base path. The only app in the workspace that loads fumadocs. Part of the `www` workspace, see the root README.

```bash
pnpm dev   # http://localhost:3002/docs (or the whole site on :3000 from the root)
```

## Layout

- `content/` - MDX source; `content/reference/` is generated by docsgen (`pnpm docs:gen` from the root)
- `app/[[...slug]]` - docs pages · `app/og` OG images · `app/llms*` llms.txt and per-page markdown · `app/api/search` fumadocs search index
- `components/provider.tsx` - fumadocs framework bridge: site-absolute URLs (`/docs/x`) on fumadocs' side, basePath-relative on Next's
- `app/fumadocs-bridge.css` - maps fumadocs' colors onto the site tokens
- `lib/source.ts` - content adapter · `lib/shared.ts` - routes + git config
- `source.config.ts` - MDX + frontmatter schema

Write links in content as site-absolute paths (`/docs/how-to/install`). Links into another zone (`/stack/nuspace`) work the same way and load that app.
